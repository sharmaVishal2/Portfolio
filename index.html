Concepts tied directly to working implementations.

System design is not abstract trivia — here is how specific principles were applied across my actual codebase.

01

Distributed Rate Limiting & State Synchronization

Implemented atomic Redis Lua scripts in the Distributed Rate Limiter to execute token deductions in a single roundtrip, preventing race conditions across multi-instance clusters.

02

Stateless Authentication & RBAC Filter Chains

Engineered Spring Security filter chains with stateless JWT validation and 3-tier Role-Based Access Control in the E-Commerce Backend, protecting customer, seller, and admin routes.

03

Relational Schema Normalization & ACID Transactions

Modeled 3NF normalized PostgreSQL entities with foreign key constraints in the E-Commerce Backend, eliminating N+1 query overhead using explicit JPQL JOIN FETCH clauses.

04

Sub-millisecond In-Memory Caching Strategies

Configured TTL-based Redis key invalidation to cache high-frequency rule lookups and token buckets, reducing backend database load under heavy concurrent bursts.

05

Applied LLM Prompt Pipelines & Error Budgets

Integrated high-speed Groq LLaMA 3 inference into SmartHire and AlgoPush with structured JSON response parsing and fallback retry strategies.
